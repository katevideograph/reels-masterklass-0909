# Лендинг мастер-класса «Хочу снимать видео»

В репозитории лежит актуальная версия сайта для открытого онлайн-мастер-класса 15/09 в 19:00 МСК.

## Как выложить сайт

1. Откройте свой созданный репозиторий на GitHub.
2. Нажмите **Add file → Upload files**.
3. Перетащите в окно файл `index.html`.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings → Pages** в меню репозитория.
6. В блоке **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
7. Нажмите **Save** и подождите 1–3 минуты.

GitHub покажет адрес сайта в этом же разделе. Обычно он выглядит так:
`https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`

Если репозиторий приватный, для публичного GitHub Pages на бесплатном тарифе лучше сделать его **Public**: Settings → General → Danger Zone → Change repository visibility.
